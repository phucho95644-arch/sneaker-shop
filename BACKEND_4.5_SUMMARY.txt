## What Was Fixed

### Root Cause: Test Rollback Logic
**File**: `backend/src/test-scripts/test_4_5.js`  
**Issue**: "Rollback invalid stock" test was setting stock to 0 BEFORE adding items to cart, making the test invalid.  
**Fix**: Modified test to add items to cart FIRST (while stock available), THEN reduce stock, THEN verify checkout fails properly.

**Result**: Test now correctly validates transaction rollback safety.
